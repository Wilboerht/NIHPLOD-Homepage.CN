## 📏 截图要求

1. **分辨率**：建议 1920x1080 或更高
2. **格式**：PNG 格式（保持清晰度）
3. **内容**：确保关键功能区域完整显示
4. **隐私**：如有真实用户数据，请打码处理

## 🔧 截图方法

### Windows
- 使用 `Win + Shift + S` 截图
- 或使用截图工具（Snipping Tool）

### Mac
- 使用 `Cmd + Shift + 4` 截取区域
- 或 `Cmd + Shift + 3` 全屏截图

### 浏览器开发者工具
1. 按 F12 打开开发者工具
2. 点击设备模拟图标
3. 选择设备类型进行响应式截图

## ⚠️ 注意事项

1. 截图前确保页面加载完成
2. 避免截取敏感信息（密码、真实用户数据等）
3. 保持截图风格统一
4. 文件命名使用英文小写，用连字符分隔
