## 一、设计原则

### 1.1 页面类型

> **一屏式设计**（仅适用于以下页面）：
> - ✅ 首页（双入口选择页）
> - ✅ AI护肤顾问 - 问题选择步骤页
>
> **常规滚动页面**：
> - 品牌故事、产品系列、产品详情、护肤仪式、联系我们、招聘页面、AI结果页等

### 1.2 悬浮卡片布局模式（Floating Card Layout）

> **核心设计理念**：底部固定背景图 + 上层悬浮可滑动内容卡片
>
> 适用于需要同时展示品牌视觉与详细内容的页面，提供沉浸式浏览体验。

#### 层级结构

| 层级 | 元素 | z-index | 说明 |
|------|------|---------|------|
| L1 | 背景图片层 | 0 | 固定定位，覆盖整个视口，展示产品/品牌图片 |
| L2 | 悬浮内容卡片 | 10 | 圆角卡片，可上下拖动，承载主要页面内容 |
| L3 | 卡片拖动指示器 | 20 | 卡片顶部的双箭头图标，提示用户可拖动 |
| L4 | 底部导航栏 | 30 | 固定在屏幕底部，始终可见 |

#### 交互规范

| 交互 | 描述 |
|------|------|
| **下拉卡片** | 用户向下拖动卡片，露出更多背景图片，卡片最小化至底部 |
| **上拉卡片** | 用户向上拖动卡片，展开更多内容，卡片几乎覆盖全屏 |
| **点击指示器** | 点击 ∨∨ 图标快速最小化卡片；点击 ∧∧ 图标快速展开卡片 |
| **滚动内容** | 卡片内部内容可独立滚动，不影响卡片位置 |
| **吸附效果** | 拖动释放后，卡片自动吸附到预设位置（展开/半开/最小化） |

```

#### 视觉规范

| 元素 | 规范 |
|------|------|
| **卡片背景** | 白色 (#FFFFFF) 或暖白 (#FAF8F5)，90-95% 不透明度 |
| **卡片圆角** | 顶部圆角 24px，底部无圆角（连接底部导航） |
| **卡片阴影** | `0 -4px 20px rgba(0,0,0,0.08)` 上方阴影 |
| **拖动指示器** | 双箭头图标，品牌金色 (#C9A86C)，点击区域 48x48px |
| **拖动手柄** | 卡片顶部居中，宽 40px 高 4px 的圆角条，浅灰色 (#E8E2D9) |
| **背景图片** | 高质量产品图，建议尺寸 1920x1080，支持视差滚动效果 |

#### 底部导航栏规范

```

```

> ⚠️ 注：本网站为品牌展示网站，产品页面仅展示产品信息并提供外部购买链接，无站内电商功能。

| 导航项 | 图标 | 跳转目标 | 说明 |
|--------|------|----------|------|
| 产品系列 | 产品图标 | 产品列表页 `/products` | 浏览产品，点击可查看详情及外部购买链接 |
| 关于我们 | 书本图标 | 品牌故事页 `/story` | 品牌故事、公司信息 |
| 加入我们 | 人群图标 | 招聘页面 `/careers` | 职位列表、企业文化 |
| 联系我们 | 邮件图标 | 联系页面 `/contact` | 联系方式、在线表单 |

#### 响应式适配

| 断点 | 卡片宽度 | 卡片边距 | 说明 |
|------|----------|----------|------|
| 移动端 (<768px) | 100% | 0 | 全宽卡片，边缘贴合屏幕 |
| 平板 (768-1024px) | 90% | 5% 两侧 | 两侧留白，居中显示 |
| 桌面 (>1024px) | 80% (max 1200px) | 自适应居中 | 限制最大宽度，保持阅读舒适度 |

#### 动画规范

| 动画 | 参数 | 说明 |
|------|------|------|
| 卡片拖动 | `spring: { stiffness: 300, damping: 30 }` | 弹性拖动效果 |
| 吸附过渡 | `duration: 0.3s, ease: ease-out` | 释放后平滑吸附 |
| 指示器切换 | `duration: 0.2s` | 箭头方向切换动画 |
| 背景视差 | `translateY: 拖动距离 * 0.3` | 轻微的视差滚动效果 |

### 2.3 品牌故事页 (Story)

#### 设计理念
采用**悬浮卡片布局**，背景展示品牌视觉大图，卡片内承载品牌故事内容。通过沉浸式体验传达品牌理念与历史。

#### 布局模式
> 使用 **1.2 悬浮卡片布局模式**

#### 页面结构
```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
