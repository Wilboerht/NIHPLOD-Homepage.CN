## 三、视觉设计规范

### 3.1 色彩系统

```
主色调 (Primary)
┌─────────────────────────────────────────────────────────────┐
│  品牌金    #C9A86C    用于Logo、重点强调、按钮               │
│  暖白      #FAF8F5    主背景色、营造温馨感                   │
│  深炭灰    #2C2C2C    主文字、高级感                        │
└─────────────────────────────────────────────────────────────┘

辅助色 (Secondary)
┌─────────────────────────────────────────────────────────────┐
│  柔粉      #F5E6E0    强调区域背景、女性温柔感               │
│  米色      #E8E2D9    卡片背景、分隔                        │
│  浅灰      #9A9A9A    次要文字、说明文字                     │
└─────────────────────────────────────────────────────────────┘

功能色 (Functional)
┌─────────────────────────────────────────────────────────────┐
│  成功绿    #7B9E87    成功状态                              │
│  警示橙    #D4A574    警示状态                              │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 字体系统

| 用途 | 英文字体 | 中文字体 | 备选 |
|------|----------|----------|------|
| 品牌标题 | Didot / Playfair Display | 思源宋体 | Times New Roman |
| 正文 | Helvetica Neue | 思源黑体 | PingFang SC |
| 辅助说明 | Montserrat | 思源黑体 Light | - |

### 3.3 字号规范

| 层级 | 桌面端 | 移动端 | 用途 |
|------|--------|--------|------|
| H1 | 48-64px | 32-40px | 页面主标题 |
| H2 | 36-42px | 24-28px | 区块标题 |
| H3 | 24-28px | 18-20px | 小标题 |
| Body | 16-18px | 14-16px | 正文 |
| Caption | 12-14px | 12px | 说明文字 |

### 3.4 间距系统

```
基础单位：8px

间距规范：
XS:  8px   - 紧凑元素间距
S:   16px  - 相关元素间距
M:   24px  - 区块内间距
L:   48px  - 区块间间距
XL:  80px  - 大区块分隔
XXL: 120px - 页面级分隔
```

### 3.5 组件风格

| 组件 | 风格描述 |
|------|----------|
| 按钮 | 圆角4px，描边1px，hover时填充变化 |
| 卡片 | 圆角8px，微妙阴影，hover时轻微上浮 |
| 输入框 | 底部描边，聚焦时品牌金色 |
| 图片 | 产品图无背景或统一浅色背景 |
