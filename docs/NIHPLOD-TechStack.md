## 三、安全设计

| 安全措施 | 实现方式 |
|----------|----------|
| 管理员认证 | JWT Token + HttpOnly Cookie |
| 密码存储 | bcrypt 加密 |
| API 保护 | 中间件验证 Token |
| 文件上传 | 类型/大小限制，重命名存储 |
| SQL 注入 | Prisma ORM 参数化查询 |
| XSS 防护 | React 自动转义 + CSP |
| CSRF 防护 | SameSite Cookie |
